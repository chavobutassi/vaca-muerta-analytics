¿Qué muestra esta página?

Un modelo BIM (formato IFC) no es solo un dibujo 3D: cada objeto de la instalación —cabeza de pozo, separador, tanque, bomba, línea— trae datos (tag, estado, fabricante, presión de diseño). Esta página valida esos datos con 7 reglas, igual que la página Calidad lo hace con la producción.

La regla R07 es el puente entre ambos mundos: cada cabeza de pozo del modelo debe corresponder a un pozo real del dataset de la Secretaría de Energía.

No existen modelos BIM públicos de instalaciones de Vaca Muerta. El modelo es una locación sintética (1 pad, 4 pozos y su batería) con errores sembrados a propósito para demostrar qué detecta cada regla. Las 3 cabezas de pozo válidas apuntan a pozos reales del dataset.

Validando registro de activos...

Validación de la información de activos entregada al regulador

Cada mes las operadoras informan a la Secretaría de Energía los datos de cada pozo (Capítulo IV): además de la producción, los atributos del activo —sigla, estado, tipo de pozo, sistema de extracción, profundidad, yacimiento, coordenadas—. Ese conjunto funciona como el registro de activos del sector.

Esta página valida esa entrega contra requisitos de información explícitos, con el enfoque de IRAM-ISO 19650: requisitos → chequeo → hallazgos → decisión sobre la entrega. Datos reales, sin modificar.
